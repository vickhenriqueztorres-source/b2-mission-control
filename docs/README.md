# O Outro Lado no Wolf AI Studio

Atualizado em: 2026-08-24  
Canal: **O Outro Lado**  
Slogan: *O que acontece depois que você clica, compra, liga ou aperta.*  
Formato: Documentários cinematográficos narrados, 16:9, sem apresentador (Faceless)  
Estética: **Industrial X-Ray / Kinetic Pop-Documentary**

O Wolf AI Studio opera o pipeline de ponta a ponta do canal **O Outro Lado**. A unidade editorial é um objeto ou fluxo (R$ 1, 1 pacote, 1 litro, 1 kWh) atravessando um sistema sob uma restrição ou gargalo, revelando o que acontece nos bastidores 24/7.

## ⚡ Comandos Principais

- `npm run hsl:abraham-sync`: Sincroniza e regenera a base de conhecimento RAG Abraham (`DOCS ABRAHAM`).
- `npm run hsl:abraham-query -- "sua busca"`: Consulta interativa/CLI ao RAG Abraham.
- `npm run hsl:pipeline-dry-run`: Executa o dry-run da cadeia editorial e diretora cinematográfica sem custo de API.
- `npm test`: Executa a suíte de testes de contratos, gates e RAGs.
- `npm run hsl:remotion-studio`: Abre o Remotion Studio para inspeção dos componentes visuais.
- `npm start`: Inicia o orquestrador de produção.
